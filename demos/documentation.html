Context Menu Kütüphanesi

Web uygulamalarınız için özelleştirilebilir, hızlı ve hafif bir sağ tık menü çözümü.

Kurulum

Gerekli dosyaları projenize ekleyin (jQuery gerektirir).

1. Temel Kullanım

En basit haliyle bir menü oluşturma. selector ile hedef elementi seçin ve items dizisiyle menü elemanlarını tanımlayın.

Buraya Sağ Tıkla (Basic) 
new RightMenu({
    selector: '#demo-basic',
    items: [
        { label: 'Yenile', action: () => alert('Yenilendi!') },
        { label: 'Ayarlar', action: () => alert('Ayarlar açıldı') },
        { separator: true }, // Ayırıcı Çizgi
        { label: 'Çıkış', action: () => alert('Çıkış yapıldı') }
    ]
});

2. İkonlar ve Kısayollar

Menü öğelerine icon (FontAwesome class) ve shortcut (görsel metin) ekleyerek zenginleştirin.

İkonlu Menü (Sağ Tıkla) 
new RightMenu({
    selector: '#demo-icons',
    items: [
        { 
            label: 'Kopyala', 
            icon: 'fa-regular fa-copy', // FontAwesome class
            shortcut: 'Ctrl+C', 
            action: () => console.log('Kopyalandı') 
        },
        { 
            label: 'Yapıştır', 
            icon: 'fa-regular fa-paste', 
            shortcut: 'Ctrl+V', 
            action: () => console.log('Yapıştırıldı') 
        }
    ]
});

3. Alt Menüler (Submenus)

Sınırsız derinlikte alt menü oluşturmak için bir öğenin içine items dizisi eklemeniz yeterlidir.

Alt Menülü Örnek 
new RightMenu({
    selector: '#demo-submenu',
    items: [
        { label: 'Anasayfa', icon: 'fa-solid fa-home' },
        { 
            label: 'Sosyal Medya', 
            icon: 'fa-solid fa-share-nodes',
            items: [ // Alt Menü Başlangıcı
                { label: 'Twitter', icon: 'fa-brands fa-twitter' },
                { label: 'Instagram', icon: 'fa-brands fa-instagram' },
                { 
                    label: 'Diğer', 
                    items: [ // 3. Seviye Alt Menü
                        { label: 'LinkedIn' },
                        { label: 'E-mail' }
                    ]
                }
            ]
        }
    ]
});

4. Dinamik Durumlar (Disabled / Hidden)

Menü öğelerini duruma göre pasif yapmak veya gizlemek için özelliklere fonksiyon atayabilirsiniz.

Dinamik Menü (Role: User) 
new RightMenu({
    selector: '#demo-dynamic',
    items: [
        { label: 'Profil', icon: 'fa-user' },
        { 
            label: 'Yönetici Paneli (Sadece Admin)', 
            icon: 'fa-solid fa-lock',
            // Hedef elementin 'data-role' özelliği 'admin' değilse pasif olur
            disabled: (target) => $(target).data('role') !== 'admin'
            // Not: 'visible' fonksiyonu kullanılsaydı tamamen gizlenirdi
        }
    ]
});

5. Koyu Tema (Dark Mode)

Yerleşik koyu temayı kullanmak için theme: 'dark' ayarını kullanın.

Koyu Tema (Dark) 
new RightMenu({
    selector: '#demo-dark',
    theme: 'dark', // Tema Ayarı
    items: [
        { label: 'Koyu Mod', icon: 'fa-solid fa-moon' },
        { label: 'Ayarlar', icon: 'fa-solid fa-cog' }
    ]
});

Ayarlar (Options)

Özellik Tip Açıklama
selector String Menünün hangi elementlerde çalışacağını belirten CSS seçicisi.
items Array Menü yapısını oluşturan nesneler dizisi.
theme String 'light' (varsayılan) veya 'dark'.
